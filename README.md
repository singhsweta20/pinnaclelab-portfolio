# 🌐 Web Development Developer Portfolio

A sleek, responsive, and modern Glassmorphic Developer Portfolio built as part of the **Web Development Internship Submission**. 

---

## 🔗 Live Demo
👉 **Live Website:** [https://singhsweta20.github.io/pinnaclelab-portfolio/](https://singhsweta20.github.io/pinnaclelab-portfolio/)

---

## ✨ Features
* 💎 **Glassmorphism UI:** Modern dark-themed design with smooth glassmorphism effects and clean typography.
* 📱 **Fully Responsive:** Optimised for desktop, tablet, and mobile views.
* 🛠️ **Interactive Skill Cards:** Visually tracks proficiency in HTML5, CSS3, JavaScript, and Git.
* 📂 **Project Showcase:** Category tabs to filter and present frontend applications.
* 📜 **Certificates & Workshops:** Highlights achievements including AI pre-summits and technical workshops.
* 🎓 **Education Timeline:** Highlights academic background in Electronics & Communication Engineering.
* 📩 **Interactive Contact Section:** Clean input layout with direct social and contact links.

---

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3 (Flexbox, CSS Grid, Modern CSS Variables)
* **Scripting:** JavaScript (ES6+)
* **Icons & Fonts:** Font Awesome 6, Google Fonts (*Inter*)
